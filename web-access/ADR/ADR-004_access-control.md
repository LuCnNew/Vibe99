# ADR-004 — Access Control Model

> **BLUF**：决定在"仅 VPN 网络可达"之上，叠加一层**共享 bearer 令牌**鉴权（令牌可内嵌于 URL/书签以保持低摩擦）。在 Gateway 边缘统一校验。更强的 mTLS/按人凭证作为延期项。

## Context

工作区经 VPN（主机 `10.8.0.154`）暴露给浏览器。浏览器访问 ≈ 在主机上获得一个 shell，属高价值目标。即便在 VPN 内也需访问控制；同时用户要求低摩擦（"输入网址就行"）。URD 约束：单用户、单工作站，默认不公网暴露。

## Options Considered

- **A. 仅信任 VPN（无应用层鉴权）**：仅靠 VPN 网络可达性。摩擦最低；仅在 VPN 完全可信且与设备绑定时才可接受。
- **B. 共享令牌 / 长效 bearer**：令牌置于 URL 或头；简单、低摩擦、可轮换。
- **C. 按访问凭证（用户名/密码或 OIDC）**：更强；摩擦更高。
- **D. 双向 TLS / 客户端证书**：强、与设备绑定；运维开销大。

## Decision

基线采用 **B（共享 bearer 令牌）**，叠加在 **A（仅 VPN 可达）** 之上。令牌在 Gateway 边缘校验，并与 VPN 网络绑定。令牌可内嵌于 URL/书签以兼顾低摩擦。mTLS（D）与按人凭证（C）延期。

## Consequences

- **优点**：低摩擦（带令牌的 URL 可书签化）；纵深防御（网络 + 密钥）；实现与轮换简单。
- **代价**：令牌泄露 ≈ shell 访问。
- **缓解**：VPN 限制 + 令牌轮换 + 可选短时令牌；单用户场景下风险可控（符合 URD）。多用户/公网场景在后续阶段引入 C/D。
