# VERIFICATION_PLAN — Vibe99 Web Access

> **BLUF**：以用户可观察的黑盒行为定义验收（不假设任何内部模块设计知识）。覆盖 URD 的每条用户保证。

1. **会话存续**：开一个 pane 跑长任务（如 `ping` / agent），关闭浏览器，重开 `127.0.0.1:<port>` → 任务仍在运行、输出连续未中断。
2. **远程接续**：同一 pane，远程浏览器经 `<HOST_IP>:<port>` 打开 → 看到同一会话与历史输出，可继续输入。
3. **scrollback 回放**：pane 产出若干输出后断开重连 → 历史输出可见，非空白。
4. **多客户端一致**：两个浏览器同时附着同一 pane → 输出一致；任一客户端输入后，双方都看到同一回显（ADR-003 自由写入）。
5. **访问控制**：无令牌 / 错令牌 → 拒绝；有效令牌（VPN 内）→ 放行；非 VPN（公网）→ 不可达。
6. **本地 + 远程同时**：`127.0.0.1` 与 `<HOST_IP>` 同时连接 → 均可正常使用。
7. **布局 / 设置恢复**：刷新或断线重连 → 当前 pane 布局与设置恢复；重启网关 → 设置恢复，但 pty 会话与 pane 布局不恢复（符合当前 ADR-002 范围）。
8. **体验阈值（VPN 网络）**：击键到回显延迟 ≤ `[TBD ms]`；文本清晰可读。
9. **断线重连**：模拟网络抖动断开 → 客户端自动重连并恢复视图，无需手动刷新。
