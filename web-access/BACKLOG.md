# BACKLOG — Vibe99 Web Access（延期特性）

> **BLUF**：以下为有意推迟到当前范围之外的**可选未来改进**（区别于 ISSUES 的"已知结构弱点"）。

- **主机重启 / 网关崩溃后自动恢复会话**——以 tmux/screen 承载实现进程级韧性。见 ADR-002 选项 B。
- **移动端 / 小屏专项优化**——响应式布局、触屏输入。
- **公网暴露 + 多用户 / 团队协作**——账号、权限、工作区隔离。见 ADR-004。
- **scrollback 落盘持久**——跨重启保留输出历史（当前仅内存）。
- **非终端（图形 / 音频）应用支持**——超出终端工作区范围。
- **会话 / 输出加密审计与长期归档**——合规与可追溯。
- **更强鉴权**——mTLS / 按人凭证（ADR-004 选项 C/D）。
